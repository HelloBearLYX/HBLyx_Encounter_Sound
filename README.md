## **Modules**
- **Encounter Sound**: set and play custom sound alert for encounter time line events and private auras
- **Lura Helper**: a broadcast helper module for L'ura encounter
- **Gossip Helper**: automatically select the registered gossip options
- **Highlight Icons**: display highlighted events(<= 5s) in icons
- **Private Aura Anchor**: anchors of debuffs and customize their icon layout
- **Timeline Skins**: customizable replacement for Blizzard's boss ability timeline
- **Text Warning Skins**: customizable replacement for Blizzard's boss text warnings
- **Countdown**: customizable replacement for Blizzard's countdown timer, with customizable sound alerts

## **模组**
- **BOSS战语音**: 为BOSS战时间线事件和私有光环设置并播放自定义音效

- **对话助手**: 自动选择已注册的对话选项
- **高亮图标**: 为高亮事件(<= 5秒)显示图标
- **私有光环锚点**: 设置减益的锚点，并自定义图标布局
- **时间轴皮肤**: 替换暴雪的首领技能时间轴, 提供自定义选项
- **文本警告皮肤**: 替换暴雪的首领文本警告, 提供自定义选项
- **倒计时**: 替换暴雪的倒计时, 提供可自定义的声音警报
